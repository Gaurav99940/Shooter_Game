Airplane Shooter (pygame)

How to run:
1. Create and activate a Python virtual environment (recommended).
2. Install dependencies:
   pip install -r requirements.txt
3. Run the game:
   python game/main.py

Controls:
- Arrow keys or A/D/W/S to move
- Space to shoot
- Esc to quit
- After Game Over press R to restart

This is a simple, standalone pygame top-down shooter using painted shapes (no external assets).
